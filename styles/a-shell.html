The 4 pieces

┌──────────┬─────────────────────────┬─────────────────────────┐
│ piece    │ answers                 │ if missing…             │
├──────────┼─────────────────────────┼─────────────────────────┤
│ WHAT     │ goal + exact location   │ explores the whole repo │
│ LIMIT    │ what not to touch       │ scope creep             │
│ DONE     │ proof it's finished     │ never stops             │
│ HOW      │ model, agents, ask      │ inherits the big model  │
└──────────┴─────────────────────────┴─────────────────────────┘

Before → after

- "Fix the failing tests"
+ "Run `test --filter=Cart`. 3 are red. Fix them one at a time,
+  re-running after each. Done when all 3 pass and nothing else breaks."

Pocket prompt

Goal: <one sentence> Only touch: <file or folder> Done when: <test / output / screenshot> Then stop and show me <what>.
