WAKE UP, DEVELOPER…

The agent does what you ask.
Not what you mean.

Better prompts mean smaller contexts, fewer runaway agents and a weekly limit that actually lasts. Four pieces. That's the whole trick.

follow the white rabbit ↓

01 // THE FORMULAFour pieces, one line each

WHATGoal and exact location.Missing → it explores the whole repo.
LIMITWhat it must not touch.Missing → scope creep.
DONEProof that it's finished.Missing → it never stops.
HOWModel, agents, ask or decide.Missing → inherits the big model.

02 // CHOOSEBlue pill or red pill

BLUE PILL · VAGUE"Fix the failing tests"
RED PILL · SCOPED"Run `test --filter=Cart`. 3 are red. Fix them one at a time, re-running after each. Done when all 3 pass and nothing else breaks."

03 // POCKET PROMPTCopy, fill, send

Goal: <one sentence> Only touch: <file or folder> Done when: <test / output / screenshot> Then stop and show me <what>.
