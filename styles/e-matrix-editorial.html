// the construct · prompt playbook

Free your context.

A field guide to prompting coding agents: ask for work they can finish, keep context small, stop paying for runaway sessions.

01FORMULA

Four pieces, one line each

WHATGoal and exact locationMissing → explores the whole repo
LIMITWhat it must not touchMissing → scope creep
DONEProof that it's finishedMissing → never stops
HOWModel, agents, ask or decideMissing → inherits the big model
02EXAMPLE

Before → after

VAGUE"Fix the failing tests"
SCOPED"Run `test --filter=Cart`. 3 are red. Fix them one at a time, re-running after each. Done when all 3 pass and nothing else breaks."
03POCKET

Copy, fill, send

Goal: <one sentence> Only touch: <file or folder> Done when: <test / output / screenshot> Then stop and show me <what>.
