NAME

prompt — ask an agent for work it can actually finish

SYNOPSIS

prompt WHAT [LIMIT] DONE [HOW]

DESCRIPTION

WHAT
goal and exact location. Without it the agent explores the whole repo.
LIMIT
what must not be touched. Without it: scope creep.
DONE
verifiable end condition. Without it the agent never stops.
HOW
model, agents yes/no, ask or decide.

EXAMPLES

"Fix the failing tests"
"Run `test --filter=Cart`. 3 are red. Fix them one at a
       time, re-running after each. Done when all 3 pass and
       nothing else breaks."

FILES

pocket prompt (click to copy) 
Goal: <one sentence>
Only touch: <file or folder>
Done when: <test / output / screenshot>
Then stop and show me <what>.
