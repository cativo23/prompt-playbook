0x00 :: INTRO

The agent does what you ask, not what you mean. Vague prompts = huge contexts = runaway agents = a weekly limit gone by Friday. This phile documents the fix. Four pieces. Read it, use it, spread it.

0x01 :: THE FORMULA

  +---------+---------------------------+-----------------------------+
  | PIECE   | ANSWERS                   | IF MISSING...               |
  +---------+---------------------------+-----------------------------+
  | WHAT    | goal + exact location     | explores the whole repo     |
  | LIMIT   | what not to touch         | scope creep                 |
  | DONE    | proof it's finished       | never stops, keeps paying   |
  | HOW     | model, agents, ask/decide | inherits the big model      |
  +---------+---------------------------+-----------------------------+

0x02 :: BEFORE / AFTER

  [-] "Fix the failing tests"

  [+] "Run `test --filter=Cart`. 3 are red. Fix them one at a
      time, re-running after each. Done when all 3 pass and
      nothing else breaks."

0x03 :: POCKET PROMPT

-- click the box to copy --

Goal: <one sentence>
Only touch: <file or folder>
Done when: <test / output / screenshot>
Then stop and show me <what>.
  greetz to everyone who ever ran out of context at 3am
